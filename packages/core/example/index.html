Introduction

Pre-release. Example data. The parts and values are not a tested build.

A 12 V control box that moves an air cylinder when START is pressed or the sensor sees a part. The pages of this example embed the guide components in a plain host page: the page owns its title, notices and text, a component only draws the BOM or a board.

Features

  • Two inputs. START button or the sensor energises the relay.
  • STOP breaks the supply to both.

Build

  1. Collect the parts from the BOM.
  2. Wire the box step by step.
  3. Connect the tubes.

Printing

The sensor bracket prints in PETG without supports.
